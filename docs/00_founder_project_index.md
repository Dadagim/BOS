# Founder Project Index

> Living document. Update it as the founder learns. One page that says who, what, and why.

## Vision
A SaaS app that helps business owners organize their business — because businesses spend money without analyzing or understanding their market and their potential.

## Current hypothesis
An AI-first business operating system for Ethiopian SMEs. A conversational layer over reliable operational workflows (inventory, sales, receivables). Vertical to investigate first: wholesalers/distributors (from research). Pharmacies and construction-material suppliers are secondary.

## Target customer
First vertical: shop owners / wholesalers-distributors in Ethiopia (Addis first).
Open question: which exact owner, what size, what tools (notebook vs phone vs Excel)?

## Current milestone
Day 1 — project foundation only. Git repo fixed, folders created, this index written. No code yet.

## Biggest unknown
Willingness to pay. Founder's own words: "I do not know how much but they will. I think so."
This is hope, not evidence. It must be tested with interviews.

## Next validation action
Gate 0: 20–30 structured interviews + 5 workflow observations with the target vertical, before building the product around it.

## Last architecture decision
None yet. First decision will be recorded as an ADR (Architecture Decision Record) so we can learn from every choice.
